关于我ABOUT

呐呐呐这里是二月哦~ 一个把技术、杂文和胡话都塞进同一个档案室的人。

WHO AM I

我是二月

白天和键盘较劲，晚上和梦境较劲。喜欢把学到的东西写下来，哪怕写得笨拙，也算给自己留一条回头的路。这个博客叫「二月的档案室」，装的是技术笔记、生活杂感，以及一些不知道该放哪里的句子。

OPEN SOURCE

关于开源

前人栽树，后人乘凉。二月对开源这类无私的行为百分百支持，也因为经常使用开源项目，希望日后也能为开源社区做出一份贡献。

STACK

手里常驻的家伙

Python 与 Nonebot 是日常，C/C++ 用来靠近底层，Rust 用来怀疑人生；Burp、IDA、pwntools 在安全这边常驻。开发侧写点 Flask、Next.js，偶尔用 Godot / SDL2 做点小玩意儿。

BELIEF

我信的几件事

一是「记录下来才算真的学会」；二是「把原理搞懂比把工具跑通重要」；三是「温柔一点，互联网已经够吵了」。

  • 学数学，顺便被数学教育

03

时间线JOURNEY

从第一篇笔记开始，把走过的路摊开来看。

  1. 2022

    第一篇笔记，从一个 C++ 的坑开始

    7 月 20 日写下「这是爷的笔记」，之后一路是 Python 复习、CSS/HTML、Nonebot 配置，以及一堆现在看来很想删掉的旧文。

  2. 2023

    Nonebot 与前后端

    给机器人写抽图系统、聊天教学，开始碰 Flask 与 Next.js，第一次意识到「能跑」和「写得对」是两件事。

  3. 2024

    靠近底层：C 库函数、SDL2、Godot、MSVC

    学 C 库函数与 WinAPI，用 SDL2 和 Godot 做小游戏，顺手记下寨板 X99 的 BIOS、SQL 注入基操和长城杯的 WP。

  4. 2025

    数学、网络与安卓

    数论、均值不等式、图灵完备；ARP、路由、Wireshark、DNS；还有 Rust 的 Cow、PDF 解密和远古安卓开发。

  5. 2026

    二进制与 Web 漏洞深水区

    Pwn 的栈溢出、Canary、栈迁移，PHP 伪协议与反序列化，JWT、SSTI、zip 伪协议，以及 WPF 的 UI 折腾。
