Important: 前置说明

1. jdk版本支持

JavaSDK原则上支持从jdk 1.8到jdk 15的OracleJDK和OpenJDK，但中间有部分版本禁用或者不支持secp256k1曲线，会导致sdk与节点之间握手失败，请首先检查当前使用的jdk是否支持secp256k1曲线，目前已经覆盖测试的jdk版本如下，推荐大家使用：

  • OracleJDK:
    • 1.8.0_141
    • 1.8.0_202
    • 11.0.2
    • 14.0.2
    • 15.0.2
  • OpenJDK:
    • 11.0.2
    • 14.0.2
    • 15.0.2

踩坑

fisco 2.x版本启动console 有SSL问题

3.x版本没有这个问题 溯源四小时无结果，默认2.x版本被淘汰

  • 尝试：
    • CA证书添加到jre信任
    • 更换多个jdk版本
    • 更换操作系统

通用参数（适用于 air 模式）

参数 说明
-C <Command> 【可选】命令类型，当前支持 deploy（部署）和 expand（扩展），默认为 deploy
-g <group id> 【可选】群组ID，默认为 group0
-I <chain id> 【可选】链ID，默认为 chain0
-v <FISCO-BCOS binary version> 【可选】FISCO-BCOS二进制版本，默认为最新版 v3.10.0
-l <IP list> 【必需】IP列表，格式为 "ip1:节点数1,ip2:节点数2"，例如："192.168.0.1:2,192.168.0.2:3"
-L <fisco bcos lightnode exec> 【可选】轻节点可执行文件路径，输入 download_binary 下载或指定正确的轻节点二进制路径
-e <fisco-bcos exec> 【可选】fisco-bcos 二进制可执行文件路径
-t <mtail exec> 【可选】mtail 二进制可执行文件路径
-o <output dir> 【可选】输出目录，默认为 ./nodes
-p <Start port> 【可选】起始端口，默认为 30300,20200（即 p2p_port 从 30300 开始，rpc_port 从 20200 开始）
-s <SM model> 【可选】是否启用国密SSL连接，默认为 false
-H <HSM model> 【可选】是否使用硬件安全模块（HSM），默认为 false
-c <Config Path> 【扩展节点时必需】指定扩展节点的配置文件路径（需包含 config.ini、config.genesis 和 nodes.json）
-d <CA cert path> 【扩展节点时必需】扩展节点时指定CA证书和私钥的路径
-D <docker mode> 【可选】是否启用Docker模式，默认为关闭。设置 -D 时使用Docker构建
-E <Enable debug log> 【可选】是否启用调试日志，默认为关闭。设置 -E 时启用
-a <Auth account> 【可选】认证模式下指定管理员账户地址
-w <WASM mode> 【可选】是否使用WASM虚拟机引擎，默认为 false
-R <Serial_mode> 【可选】是否使用串行执行，默认为 true
-k <key page size> 【可选】键值分页大小，默认为 10240
-m <fisco-bcos monitor> 【可选】是否启用节点监控，默认为 false
-i <fisco-bcos monitor ip/port> 【可选】扩展节点时需指定监控服务的IP和端口
-M <fisco-bcos monitor> 【可选】扩展节点时指定Prometheus监控工具的路径
-z <Generate tar packet> 【可选】打包链上数据生成tar包
-n <node key path> 【可选】设置节点密钥文件路径以加载节点ID
-N <node path> 【可选】设置需修改为多CA模式的节点路径
-u <multi ca path> 【可选】设置多CA模式下其他CA的路径
-6 <ipv6 mode> 【可选】是否启用IPv6模式（默认监听 ::），默认为 false
-T <Consensus Algorithm> 【可选】共识算法，默认为 PBFT，可选 pbft / rpbft（推荐 pbft）
-h 显示帮助信息

Pro/Max 模式专用参数

参数 说明
-C <Command> 【可选】命令类型，当前仅支持 deploy（部署），默认为 deploy
-g <group id> 【可选】群组ID，默认为 group0
-I <chain id> 【可选】链ID，默认为 chain0
-V <chain version> 【可选】链版本，支持 air、pro、max，默认为 air
-l <IP list> 【必需】IP列表，格式同通用模式
-p <Start port> 【可选】起始端口，默认为 30300,20200,40400,2379（即 p2p_port 从 30300 开始，rpc_port 从 20200 开始，tars_port 从 40400 开始，tikv_port 默认为 2379）
-e <service binary path> 【可选】RPC网关节点服务的二进制路径
-y <service binary download type> 【可选】RPC网关节点服务二进制下载类型，默认为 cdn
-v <service binary version> 【可选】服务二进制版本，默认为最新版 v3.10.0
-r <service binary download path> 【可选】服务二进制下载路径，默认为 binary
-c <Config Path> 【可选】指定部署节点的 config.toml 配置文件路径
-t <deploy type> 【可选】部署类型，支持 rpc、gateway、node、all，默认为 all
-o <output dir> 【可选】输出目录，默认为 generated
-s <SM model> 【可选】是否启用国密SSL连接，默认为 false
-h 显示帮助信息
