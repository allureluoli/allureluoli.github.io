保留的是 Vue 2 风格源码分析，依赖模板、静态资源和后端接口，不能当作一个独立的 Vue 3 项目直接运行。

关于vue 组件

我们直接上源码分析

index.js

  1. 未登录时 → 显示登录界面
  2. 登录后 → 显示功能页面（农场/消费者等）
  3. 头部导航始终显示用户信息
  4. 分页控件用于数据翻页

核心逻辑：

  • 登录成功：login = true，显示对应页面
  • 退出登录：login = false，回到登录界面

main.js

Farm（农场）

  • 功能：生产食品，显示食品列表
  • 特点：可以新建食品，有分页表格

Agent（中间商）和 Mall（超市）

  • 功能：基本相同（使用mixin共享代码）
  • 区别：user值不同（1=中间商，2=超市）

Consumer（消费者）

  • 功能：查询食品溯源信息
  • 特点：输入溯源码查看食品来源

核心区别：

  • 农场：生产食品
  • 中间商/超市：流通食品
  • 消费者：查询食品信息

就像食品产业链：生产→流通→消费！

login.js

两步登录流程：

  1. 选择身份：点击生产商/中间商/超市/消费者
  2. 自动登录：5秒倒计时后自动进入对应页面

特殊处理：

  • 非消费者：显示区块链地址
  • 消费者：直接登录（无地址）
  • 可点击”直接登录”跳过倒计时

登录结果：

  • 进入对应角色页面（农场/中间商/超市/消费者）

components.js

Header（头部组件）

  • 显示logo和平台名称
  • 登录后显示当前用户身份

FoodDetail（食品详情）

  • 显示食品基本信息
  • 格式化显示时间

TraceDetail（溯源详情）

  • 显示完整食品流转信息
  • 根据用户权限显示不同内容：
    • 消费者：看到全流程（农场→中间商→超市）
    • 超市：看到农场→中间商
    • 中间商：只看到农场

AddVegetable（添加食品）

  • 中间商/超市使用：接收食品并质检
  • 需要输入质检结果和收货单位

CreateVegetable（创建食品）

  • 农场使用：创建新食品
  • 需要输入溯源码、食品名称等

核心功能：

  • 时间统一格式化显示
  • 权限控制显示不同信息
  • 质检状态：0=优质，1=合格，2=不合格
