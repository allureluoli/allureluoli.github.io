题面中的三个起始端口与记录中实际使用的两个端口参数存在版本差异。这份记录不能证明所有题面要求已完成，复现时应逐项核对节点配置与监听端口。

  1. 进入WeBASE-Node-Manager目录，完成数据库初始化操作；

  3. 使用命令启动WeBASE-Node-Manager管理平台服务，并检查节点管理是否正常启动；

  4. 使用swagger对节点管理服务的 API 接口测试
