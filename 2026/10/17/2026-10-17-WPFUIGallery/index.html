什么是Fluent风格

Fluent 风格就是微软的一套界面设计语言，Windows 11 的设置、文件资源管理器等界面，就能让你直观感受到这种风格。

它不只是“圆角”，还包括这些特点：

| 特点 | 直观表现 | | ————– | —————————————— | | 圆角与简洁布局 | 按钮、输入框、卡片边角柔和，留白充足 | | 层次感 | 用背景、边框、阴影区分页面、卡片和弹窗 | | 材质效果 | 部分背景带有半透明、模糊或壁纸色调 | | 交互反馈 | 鼠标悬停、点击、切换页面时有颜色变化和动画 | | 统一的视觉规范 | 字体、图标、间距、配色保持一致 | | 浅色与深色主题 | 两种模式下都有协调的颜色和对比度 |

Binding

数据绑定练习开始，想起了三年前初学mvvm的日子 ~

小记： Orientation="Horizontal" 表示排列方向为“水平”，也就是从左到右排列。

理解：

  • Text= 绑定的属性 也就是当前控件的文字
  • Binding 建立数据绑定
  • {}内是可执行的特殊语法代码，叫做标记扩展 (Markup Extension)
  • 选择的ElementName是什么
  • 获取xx的什么属性

整体样式定义

  • 在 <ui:FluentWindow.Resources>中 通过 Style 可以统一修改

使用示例：

  • <TextBlock Text="First class, Click Button" Style="{StaticResource CardTitleStyle}"/>

  • <TextBlock Text="Please Input Name" Style="{StaticResource CardTitleStyle}"/>

小记：

  • Resources：存放可复用资源，这里供当前窗口使用

  • x:key="Card"：给样式一个查找名称

  • setter：指定要设置的属性和值

  • StaticResource CardTitleStyle：查找并使用这个样式

  • TargetType="TextBlock"：样式适用于 TextBlock
